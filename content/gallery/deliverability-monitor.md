Automated inbox/spam placement testing, running on a schedule across every sending server and seed mailbox. Each run breaks results down server-by-server — inbox count, spam count, and anything ambiguous — so a placement problem on one specific server is caught before it's mixed into aggregate numbers that hide it.

This is the system referenced in the [Log post on why emails land in spam](/log/why-emails-land-in-spam) — the automated version of the seed testing described there.
